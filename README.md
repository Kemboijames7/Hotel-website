### **Hotel Booking Website – README**  

#### **Overview**  
The Hotel Booking Website is a user-friendly platform that allows customers to search, compare, and book hotel rooms seamlessly. The platform provides a smooth booking experience with secure payments, real-time availability updates, and customer support features.  

#### **Features**  
- **Hotel Search & Filtering** – Find hotels based on location, price, ratings, and amenities.  
- **Real-Time Availability** – Check room availability and make instant reservations.  
- **Secure Online Payments** – Pay using credit/debit cards, PayPal, or mobile payments.  
- **User Authentication** – Sign up/log in to manage bookings and view history.  
- **Booking Confirmation & Notifications** – Receive instant email and SMS confirmations.  
- **Customer Reviews & Ratings** – Read and leave reviews for hotels.  
- **Admin Dashboard** – Manage hotel listings, pricing, and customer bookings.  
- **Interactive Maps** – View hotel locations using Google Maps integration.  

#### **Technology Stack**  
- **Frontend:** HTML, CSS, JavaScript, React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas)  
- **Authentication:** JWT (JSON Web Token)  
- **Payment Integration:** Stripe/PayPal  
- **API Communication:** RESTful API with Fetch/Axios  

#### **How to Run the Project**  
1. Clone the repository:  
   ```sh
   git clone <repo-url>
   ```
2. Navigate to the project directory:  
   ```sh
   cd hotel-booking-website
   ```
3. Install dependencies:  
   ```sh
   npm install
   ```
4. Start the development server:  
   ```sh
   npm start
   ```
5. Open in the browser:  
   ```
   http://localhost:3000
   ```
